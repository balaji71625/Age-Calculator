# Age Calculator – JavaScript DOM Project

A simple and interactive **Age Calculator** built using **HTML, CSS, and JavaScript**.  
This project calculates a user’s **exact age** based on the selected date of birth and demonstrates the use of **JavaScript DOM manipulation and date handling**.

## ✨ Features
- Calculate age based on date of birth
- Displays age in **years, months, and days**
- Validates user input
- Clean and user-friendly UI
- Instant result using JavaScript logic
- Fully responsive design

## 🛠️ Technologies Used
- **HTML5** – Structure of the page  
- **CSS3** – Styling and layout  
- **JavaScript (Vanilla JS)** – Logic, date calculations, and DOM manipulation
